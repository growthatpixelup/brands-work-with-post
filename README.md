# Comments for the "Brands we want to work with" post

A single page with 40 ready-to-post comments for PIXELUP's launch on X. Friends open the link, pick a line, and copy it or open a pre-filled reply.

## Go live with GitHub Pages

1. Upload `index.html` (and this README) to the root of this repo on the `main` branch.
2. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, and save.
3. After a minute the page is live at **https://growthatpixelup.github.io/brands-work-with-post/**

## When the post is live

Open `index.html`, find `POST_URL` near the top of the script, and paste the X post link. Commit, and the Reply on X and Quote post buttons will point at the post.

## Editing comments

All comments are in the `COMMENTS` list in `index.html`. Add, remove, or reword lines there.
